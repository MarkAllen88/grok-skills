# Grok Skills

A public catalog of 195 `SKILL.md` files for [Grok Bot](https://docs.x.ai/grok-bot/overview). Skills only — no website.

## Install

Clone and copy any skill into Grok’s skills folder:

```bash
git clone https://github.com/jaskirat1616/grok-skills.git
cp -R grok-skills/skills/<skill-name> ~/.grok/skills/
```

Or add the whole catalog as a marketplace source:

```bash
grok plugin marketplace add jaskirat1616/grok-skills
```

Each skill lives at `skills/<name>/SKILL.md`.
